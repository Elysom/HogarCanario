# HogarCanario

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.0.7.

Webpage made in angular of a concept design for a cultural instituion in Seville.

The webpage is hosted in [hogarcanario.netlify.app](https://hogarcanario.netlify.app/)
The server API its deployed in vercel so it can take a little bit of time from the first GET to the response.
